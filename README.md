## Password-Gen
Generador de contraseñas seguras hecho en python para practicar.
### Características:
- Genera contraseñas basadas en una enorme lista de palabras.
- Valida la seguridad de las contraseñas según criterios básicos como:
	- Al menos una minúscula.
	- Al menos una mayúscula.
	- Al menos un numero.
	- Al menos un símbolo.
	- Longitud de 8 a 32 caracteres.
- Crea contraseña con palabras que tu mismo selecciones.
